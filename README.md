# Atelier Showroomprivé : contrats d'API avec Postman

Dépôt de l'atelier de la Guilde Tech du 5 novembre 2026.

| Fichier | Contenu |
| --- | --- |
| `contrats/ventes-openapi.yaml` | Contrat synchrone de l'API Ventes (OpenAPI 3.0, 4 opérations) |
| `contrats/ventes-asyncapi.yaml` | Contrat asynchrone du message `vente.publiee` sur Azure Service Bus (AsyncAPI 2.6) |

Pour commencer, forkez ce dépôt sur votre compte GitHub (bouton **Fork**), clonez votre fork, puis suivez le guide participant distribué pendant la session. Chacun travaille dans son propre fork, sur une branche `atelier/<prenom>`.
